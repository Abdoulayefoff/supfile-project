# SUPFile - Cloud Storage Platform

## Description
Plateforme de stockage cloud développée dans le cadre du projet 4PROJ.

## Stack Technique
- **Backend** : Symfony (PHP)
- **Frontend Web** : React 18 + TypeScript + Vite
- **Frontend Mobile** : React Native + Expo
- **Base de données** : MySQL 8.0

## Branches
- `master` : Production (protégée)
- `develop` : Développement (intégration)
- `feature/*` : Branches de fonctionnalités

## Workflow
1. Créer une branche depuis `develop`
2. Développer la fonctionnalité
3. Push et créer une Pull Request vers `develop`
4. Après review, merge dans `develop`
5. Quand `develop` est stable, merge dans `master`
